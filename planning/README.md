# Planning

Plans for this project live here, one folder per plan, named `<YYYY-MM-DD>-<name>/`, tracked in
git so every checkout (and the other computer) has them. Each folder holds `notes.md` (discovery,
questions, answers, scope changes), `plan.md` (the entry point for implementation) and numbered
milestone or phase files; `_DONE.md` is written only when the work is implemented. Finished plans
move to `_archive/`. The settled decisions are also recorded in the matching `docs/*-plan.md`, which
is what later agents read first.

Not the Skybridge workspace: that is work. This is Rocky's personal project (2026-11-25).

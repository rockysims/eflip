# Show one unit when nothing is worth buying

- Situation: a row whose estimate recommends 0 units showed fallback figures (raw best prices) instead of a real cost, ROI, days to clear and daily profit, so the row could not be judged.
- Proposed: leave the quantity at 0 with the fallback figures.
- Chosen: the estimate shows 1 unit from the cheapest source order so every figure is real; the row stays filtered, now with the reason "nothing to buy", so the floor changes what the row shows, not which rows pass. A factor other than 1 scales from that 1 unit.
- Why: "I'd like the recommended quantity to have a floor of 1 (so I can still see its ROI, etc.)" (owner's words). Keeping the row filtered is the agent's reading of that reason; revisit if the owner wants such rows to pass.
- Pattern: none
- Status: ruling

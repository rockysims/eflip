# The character is a sortable column

- Situation: a table pooling several characters' orders showed the character as a dim first name inside the item cell, and the default order was by verdict; the column headers were already sortable but the owner did not find it.
- Proposed: make the default sort by character.
- Chosen: a "character" column after "item" (first name, full name in the tooltip), sortable like every other and hidden while one character has rows; the default order stays by verdict; the note above the table says "click a column title to sort".
- Why: "the primary sort should be by character (or better yet make the columns sortable on click (so I can sort either by verdict or character at least)" (owner, 2026-11-26).
- Pattern: none
- Status: ruling
